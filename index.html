Lucky Relay Color Machine

Paste a long monologue. Start the webcam and mic. Pass the laptop around. Read the scrolling text. The machine turns voice, face motion, missed words, and panic into color. Finish to export the happening as a video.

How to Use

  1. Paste the text below. Keep it local. Nothing uploads.
  2. Press Start camera + mic, then Begin recording.
  3. One person reads while holding the laptop or sitting in front of it.
  4. Pass it on whenever it feels right. Use Next reader to mark the switch.
  5. Use Random speed when the room needs trouble.
  6. Press Finish. The page gives you a phone-shaped MP4 when the browser supports it, otherwise WebM.
